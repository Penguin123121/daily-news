# 每日新闻工具 UI 美化 — 设计文档

## 目标

将每日新闻 HTML 报告从现有简单样式升级为「传统中式邸报」风格，提升视觉品质和品牌感。

## 设计方向：传统中式邸报

深红匾额 + 干支纪年 + 朝闻暮览 + 宋体字，浓郁的传统新闻邸报气质。

## 配色

| 元素 | 颜色 | 说明 |
|------|------|------|
| 页面背景 | `#faf6ef`（米宣纸色） | 模拟古纸质感 |
| Header 渐变 | `#6b1000` → `#8b0000`（深朱红） | 匾额式头部 |
| Header 文字 | `#f5e6c8`（象牙金） | 与红底古典对比 |
| 早间标识色 | `#c0392b`（朱红） | 朝闻标签/序号/左色条 |
| 晚间标识色 | `#2c3e50`（墨蓝） | 暮览标签/序号/左色条 |
| 卡片背景 | `#fff` | 干净阅读层 |
| 卡片边框 | `#e8d5c4`（淡棕） | 温润分隔 |
| 正文 | `#333` / `#888`（层次灰） | 层次分明 |

## 字体

- 标题/装饰：`Georgia, "Noto Serif SC", "Source Han Serif SC", serif`
- 正文：`"PingFang SC", "Microsoft YaHei", sans-serif`
- 等宽/代码：保持系统默认

## 页面结构

1. **匾额式 Header** — 深朱红渐变背景，象牙金文字；大字「每日新闻」+ 干支纪年日期 + 「央视新闻」来源标注
2. **日期 Tab 栏** — 3 天切换，选中态朱红底象牙金字；公历日期 + 农历日期（如 四月廿一）
3. **新闻面板**（按日期 tab 切换）：
   - 早间板块：「朝闻」标签 + 5 条精致新闻卡片
   - 晚间板块：「暮览」标签 + 5 条精致新闻卡片
4. **Footer** — 数据来源声明（央视新闻链接）+ 自动生成说明

## 新闻卡片设计

每条新闻一张独立卡片：

- **左侧**：中文数字序号（一/二/三/四/五），朱红（朝闻）或墨蓝（暮览）底色方块
- **右侧**：
  1. 标题（加粗、衬线体）
  2. 时间（小字灰色）
  3. 新闻配图（如有，圆角、懒加载、加载失败时隐藏）
  4. 摘要（正文灰色，两端对齐）
  5. 「查看原文 →」链接

卡片悬停：轻微上浮 + 阴影加深。

## 时段标识

- 早间板块标题：「朝闻」标签（朱红底），附「更新于 08:00」
- 晚间板块标题：「暮览」标签（墨蓝底），附「更新于 20:00」

## 响应式

- 保持 max-width: 800px 容器居中
- 移动端字体适当缩小
- 图片 max-height: 280px → 移动端 200px

## 修改文件

- `fetch_news.py` — 仅修改 `generate_html()` 函数中的 CSS 和 HTML 模板部分，以及 JS 中的 `buildNewsItem`/`buildPeriodSection`/`buildTab`/`buildPanel` 函数

## 不变更

- 数据获取逻辑（API 调用、聚合、去重）
- 文件保存/加载逻辑
- 日期/时段判断逻辑
- 自动补全机制
- HTML 单文件自包含架构
- 3 天数据保留 + 日期 Tab 切换机制
